# ZZRCC
ZZRCC (Z280, RAM, CPLD, and CF disk) is the replacement for ZZ80CF, a Z280 SBC operating in Z80 compatible mode.  It fixed the asynchronous baud clock that intermittently injected an extra character in the serial output.
